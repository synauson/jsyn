# Contributing

This repository is published from jsyn's releases. Each commit on `main` is one
release, tagged `vX.Y.Z` and listed under Releases with its notes from
[CHANGELOG.md](CHANGELOG.md). jsyn is developed elsewhere, so this repository doesn't
take pull requests.

To report a problem or ask a question, see [SUPPORT.md](SUPPORT.md). To report a
security problem, see [SECURITY.md](SECURITY.md).
